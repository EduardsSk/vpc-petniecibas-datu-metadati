# Demo dati

Šī mape satur datu failus, uz kuriem atsaucas slaidi (1.–4. tematiska sesija). Faili ir _faktiski_ metadatu eksporti no reālām datu kopām (QVUERT, SMGJHG, Athar, Ikstens, Krodznieka 6KFIIY) — tā tos lekcijā var vērot tieši, salīdzināt formātus un strukturālas atšķirības.

> **Praktisko uzdevumu faili** atrodas atsevišķi: katra praktiskā uzdevuma direktorijā `practice/<temats>/data/`. Šajā mapē atrodamie faili ir tikai tie, ko slaidi izmanto demonstrēšanai.

## Saturs pa tematiem

- `1-findable/` — Topic 1 demo dati (QVUERT eksporti, Ikstens-Zenodo kontrasts, Signposting/linkset)
- `2-accessible-interoperable/` — Topic 2 demo dati (DOI content negotiation, F-UJI ziņojums, OAI-PMH Identify)
- `3-interoperable/` — Topic 3 demo dati (saistīto datu graf-fragments, Wikidata SPARQL paraugs, CVOC widget ekrānuzņēmums)
- `4-reusable/` — Topic 4 demo dati (R1 atribūtu paraugi: QVUERT, Ikstens, Krodznieka 6KFIIY)
