# Pētniecības datu metadatu izveide

Mācību semināra "Pētniecības datu metadatu izveide: kvalitāte, standarti, dokumentācija" materiāli (VPC, 2026. gada 5. maijs).

Seminārs piedāvā praktisku ievadu pētniecības datu metadatu pārvaldībā saskaņā ar FAIR principiem. Aplūkotie standarti — Dublin Core, DataCite, schema.org, JSON-LD; izmantotie rīki — Wikidata Query Service, F-UJI, Dataverse API, [dataverse.lv](https://dataverse.lv). Mērķauditorija: datu kuratori, pētnieki, doktorantūras studenti, bibliotēku un atmiņas institūciju darbinieki.

Organizē Augstākās izglītības un zinātnes IT koplietošanas pakalpojumu centrs (VPC) projekta "Atbalsts atvērtās zinātnes ieviešanai praksē..." (Nr. 2.1.3.1.i.0/2/23/I/CFLA/002) ietvaros.
